● System Design
Real-Time Collaborative Task Board
One backend service · REST for CRUD · WebSocket rooms for live sync · Postgres as source of truth
Client
Browser — React SPA
React 19 + Router Zustand @dnd-kit board Tailwind CSS
Optimistic UI updates, reconciled by REST responses and live WebSocket events.
Application
Backend API
Express / Fastify Socket.IO rooms JWT auth + refresh RBAC middleware Optimistic-lock (version)
Every mutation: validate role → write to Postgres → publish event to Redis → broadcast to the board’s WebSocket room.
Storage
PostgreSQL
Users & workspaces Boards & cards Comments
The single source of truth. Everything else is derived or cached.
Ephemeral state
Redis
Pub/sub fan-out Presence sets Read cache
Lets a second backend instance join later with zero app changes.
